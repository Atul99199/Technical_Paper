# Django ORM 

### 1. How do you use ORM queries in Django Shell?
> Django ORM queries can be executed inside the Django shell using `python3 manage.py shell`.  
> Example: `Question.objects.all()` retrieves all Question objects.

### 2. How do you convert ORM queries to SQL?
> You can use `.query` to see the SQL generated by a Django ORM query.  
> Example: `print(Question.objects.all().query)`.

### 3. What are Aggregations?
> Aggregation calculates a single result from multiple database records, such as `Count`, `Sum`, `Avg`, `Max`, and `Min`.  
> Example: `Question.objects.aggregate(Count("id"))`.

### 4. What are Annotations?
> Annotations add calculated values to each object returned by a query.  
> Example: `Question.objects.annotate(choice_count=Count("choice"))`.

### 5. What is a Migration File?
> A migration file contains instructions for applying changes made to Django models to the database.  
> We create migrations using `makemigrations` and apply them using `migrate`.

### 6. What are SQL Transactions?
> A transaction is a group of database operations treated as one unit of work.  
> Either all operations succeed, or the changes can be rolled back.

### 7. What are Atomic Transactions?
> An atomic transaction ensures that a group of database operations is completed completely or none of the changes are saved.  
> Django provides this using `transaction.atomic()`.
